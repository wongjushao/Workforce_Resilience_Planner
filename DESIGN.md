# Style
The style is defined by a deep navy background (#030712) with a subtle 40px grid pattern. It uses glassmorphism (12px blur, 10% white border) for all containers. Typography pairs heavy, industrial Cabinet Grotesk for headings with the geometric Satoshi for body text. The primary color is a vibrant Cyan (#00f2ff) paired with a deep Purple (#7000ff) in mesh gradients.
## Spec
Create a futuristic dark-mode UI style. Background: #030712 with a 40px square grid in rgba(255,255,255,0.05). Primary accent: #00f2ff (Cyan); Secondary accent: #7000ff (Purple). Typography: Headings in 'Cabinet Grotesk' (900 weight, tight tracking), Body in 'Satoshi' (400-500 weight). Components must use 'Glassmorphism': background rgba(255,255,255,0.03), backdrop-filter blur(12px), border 1px solid rgba(255,255,255,0.1). Interactive cards should include a 3D tilt effect: perspective(1000px) rotateX(4deg) rotateY(-4deg). Include a scanning 'glow-line' animation: 1px height gradient (transparent, #00f2ff, transparent) moving horizontally across containers. Buttons: Primary buttons should be solid #00f2ff with a 20px cyan shadow glow; Secondary buttons should be glass with white text.
